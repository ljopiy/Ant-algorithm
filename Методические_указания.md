## 2. Постановка задачи

### 2.1. Классическая TSP
Дано n городов (пунктов) и матрица расстояний D = (dᵢⱼ).  
Нужно найти **гамильтонов цикл** минимальной длины: посетить каждый город ровно один раз и вернуться в исходный.

Задача NP-трудная: при росте n полный перебор быстро становится невозможным, поэтому используют эвристики и метаэвристики (в т.ч. ACO).

### 2.2. Транспортная / курьерская интерпретация
В рамках лабораторной:
- **города** = пункты доставки (адреса клиентов, склады микрорайонов);
- **длина маршрута** = суммарный пробег курьера / транспорта;
- **старт** условно — склад (можно считать пунктом 0);
- цель — объехать все пункты и вернуться на склад с минимальным пробегом.

Такая постановка напрямую связана с логистикой «последней мили», планированием обходов инспектора, маршрутом сервисной бригады и т.п.

В коде расстояния — **евклидовы** по координатам (x, y). Для учебной цели этого достаточно; в реальной логистике вместо них берут дорожный граф (OSM, матрица времени в пути).

## 3. Теория муравьиного алгоритма (Ant System)

### 3.1. Биологическая идея
Муравьи при поиске пищи оставляют на пути **феромон**. Короткие удачные тропы проходятся чаще → феромона больше → следующие муравьи чаще выбирают эти тропы. Длинные тропы «забываются» из‑за испарения феромона.

### 3.2. Основные величины

| Обозначение | Смысл |
|-------------|--------|
| τᵢⱼ | феромон на ребре (i, j) |
| ηᵢⱼ = 1 / dᵢⱼ | эвристическая привлекательность (короче → лучше) |
| α (alpha) | сила влияния феромона |
| β (beta) | сила влияния эвристики |
| ρ (rho) ∈ (0, 1) | доля испаряемого феромона за итерацию |
| Q | константа отложения феромона |
| Lₐ | длина маршрута муравья a |

### 3.3. Выбор следующего города
Пусть муравей находится в городе i, множество ещё не посещённых городов — Jᵢ. Тогда вероятность перехода в город j:

**Pᵢⱼ = ( τᵢⱼ^α · ηᵢⱼ^β ) / Σₖ∈Jᵢ ( τᵢₖ^α · ηᵢₖ^β ) ,** где j ∈ Jᵢ.

Иными словами: чем больше феромона на ребре и чем короче ребро, тем выше шанс его выбрать (с учётом показателей α и β).

### 3.4. Обновление феромона
После того как все муравьи построили маршруты:

**τᵢⱼ ← (1 − ρ) · τᵢⱼ + Σₐ Δτᵢⱼᵃ**

где **Δτᵢⱼᵃ = Q / Lₐ**, если муравей a прошёл ребро (i, j), иначе **0**.

**Интуиция параметров:**
- большой α — сильнее «коллективная память» (риск преждевременной сходимости);
- большой β — сильнее жадность по коротким рёбрам;
- большой ρ — быстрее забываются старые тропы (больше исследование);
- малое ρ — дольше сохраняется накопленный опыт.

В лабораторной реализован классический **Ant System** (симметричная TSP).

## 6. Вариативность заданий

Преподаватель / студент выбирает **номер варианта** V (например, по номеру в журнале).  
Ниже — что именно менять, чтобы получить **другой** численный результат.

### 6.1. Выбор карты (обязательный параметр варианта)

| V mod 4 | Карта | Команда |
|---------|-------|---------|
| 0 | `demo` (6 пунктов) | `--map demo` |
| 1 | `ring` (кольцо) | `--map ring` |
| 2 | `clusters` (два района) | `--map clusters` |
| 3 | случайная | `--map random --cities N --seed S` |

Для случайной карты:
- N = 10 + (V mod 6) → от 10 до 15 городов;
- S = 100 + V (фиксированный seed → воспроизводимость).

Пример для V = 11: `11 mod 4 = 3` → random, N = 15, S = 111:
```bash
python src/run_lab.py --map random --cities 15 --seed 111 --no-show
```

### 6.2. Обязательная серия экспериментов с параметрами
На **своей** карте выполнить три прогона:

| Прогон | Что меняем | Пример |
|--------|------------|--------|
| A (базовый) | α = 1, β = 5, ρ = 0.5 | значения по умолчанию |
| B | увеличить β (сильнее жадность) | `--beta 8` |
| C | увеличить ρ (быстрее забывание) | `--rho 0.8` |

Дополнительно (по желанию / для повышенного балла):
- изменить число муравьёв `--ants 10` и `--ants 40`;
- изменить число итераций `--iters 50` и `--iters 200`;
- сравнить два seed на одной random-карте.
